# Strawberry Todo 🍓

A cute productivity application built with React and Vite.

## Features

- Add, edit and delete tasks
- Priority levels
- Due dates
- Search
- Sorting
- Progress tracking
- XP & Level system
- Daily streak
- Achievements
- Theme switcher
- Drag & Drop
- Responsive design
- LocalStorage persistence

## Technologies

- React
- Vite
- CSS3
- JavaScript (ES6)
